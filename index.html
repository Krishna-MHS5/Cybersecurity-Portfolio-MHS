PROJECT 01

AWS Cloud Hosting & Security Implementation

Cloud infrastructure deployment, access management and secure content delivery.

Project Overview

Designed, deployed and tested a static portfolio using AWS cloud infrastructure. The project involved configuring Amazon S3 for static hosting, managing access permissions, setting up Amazon CloudFront and testing HTTPS access.

Access Management

AWS IAM permissions and S3 bucket policies were configured as part of the implementation.

Practical Implementation

Security Objectives

Applied key security principles to build a safer website.
  • Implemented HTTPS encryption to secure website communication
  • Configured private cloud storage and access controls
  • Applied least-privilege access principles to manage resource permissions
  • Implemented website security headers to strengthen browser-side security.

Project Outcomes & Learning

Successfully deployed and tested a static portfolio using AWS infrastructure. Developed practical understanding of cloud hosting, access permissions, content delivery and HTTPS configuration.

AWS resources were decommissioned after testing to avoid unnecessary ongoing costs.

Testing And Validation

Conducted testing to validate website navigation, interactive functionality, responsive behaviour and browser console performance. Reviewed AWS security configurations and access controls to assess deployment security.
